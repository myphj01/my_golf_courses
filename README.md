## 주요 기능

### 4가지 보기 모드
- **카드 그리드**: 이미지형 카드로 한눈에 비교, 추천 코스는 금색 테두리 강조
- **테이블**: 정렬·비교에 최적화된 표 형식
- **가격 차트**: 주중·주말 그린피 막대 차트 (지역별 색상 구분)
- **지역 요약**: 권역별 평균 가격·특징 요약

### 필터 & 정렬
- **지역 칩**: 수도권·경기도·강원도·충청도·경상도·전라도·제주도
- **코스 유형**: 퍼블릭 / 회원제 / 리조트
- **가격 범위**: 슬라이더로 주중 그린피 범위 설정
- **미수록 포함 토글**: 기본 OFF → ON 시 미수록 코스도 목록에 표시
- **정렬**: 추천순 / 가격 낮은순 / 가격 높은순 / 이름순
- **검색**: 골프장 이름 실시간 검색

### 상세 모달
코스 카드 클릭 시 다음 정보를 표시합니다:
- 위치, 홀 수, 파, 코스 유형
- 주중·주말 그린피
- 접근 방법 (서울 기준 소요 시간, 교통편)
- 코스 특징
- 장점 / 단점
- 추천 점수 (100점 만점)
- 회원권 가격 (해당 코스)

### 미수록 코스 직접 입력 (localStorage)
상세 데이터가 없는 미수록 코스에서 "+ 정보 직접 입력" 버튼을 누르면 입력 폼이 열립니다.

저장 가능한 항목:
- 주중·주말 그린피, 홀 수, 코스 유형
- 회원권 가격 (선택)
- 접근성 정보, 코스 특징, 장단점
- 추천 점수, 메모

입력 데이터는 **브라우저 localStorage에 저장**되며, 새로고침 후에도 유지됩니다.  
저장된 코스는 초록색 카드와 "직접입력" 배지로 구분됩니다.

## 파일 구조

```
골프장 조사/
└── index.html      # 전체 앱 (HTML + CSS + JS 단일 파일)
```

모든 코드와 데이터가 `index.html` 하나에 포함되어 있습니다.  
외부 라이브러리 의존성 없음 (순수 Vanilla JS).

### index.html 내부 구조

```
1. HTML 헤더 및 메타 정보
2. CSS 스타일 (전체 UI, 반응형, 다크 모드 준비)
3. const COURSES = [...] — 430개 코스 데이터 배열
4. const REGION_DATA = {...} — 7개 권역 요약 데이터
5. JS 함수 (렌더링, 필터, 정렬, 모달, localStorage 관련)
6. HTML 본문 (헤더, 필터 바, 뷰 컨테이너, 상세 모달, 미수록 입력 모달)
```

**상세 수록 코스:**

### 주요 참고 자료
- **공공데이터**: 문화체육관광부 골프장 현황 (2026년 527개 운영 기준)
- **예약 플랫폼**: [김캐디](https://kimcaddie.com), [더블이글](https://dbegl.com)
- **지자체 공식 자료**: 용인시청 골프장 현황 (26개 코스)
- **기업 공식 홈페이지**: 삼성물산 베네스트골프, 아코르 계열, KCC 계열 등
- **골프 전문 매체**: 골프매거진 코리아, 골프다이제스트 코리아

### 조사 지역별 특이사항

**경기도 (186개 수록)**  
전국 최다 골프장 밀집 지역. 용인시에만 26개+ 코스가 있으며, 파주·포천·이천·여주·안성 등 수도권 외곽으로 분포. 회원제 명문 클럽(레이크사이드CC, 수원CC, 한양CC 등)과 가성비 퍼블릭이 공존.

**경상도 (83개 수록)**  
부산·경남권 클럽과 남해안 리조트 코스가 특징. 사우스케이프CC, 가야CC, 부산CC 등 세계적 수준의 코스 다수. 전반적으로 수도권 대비 30~40% 저렴.

**전라도 (66개 수록)**  
전국에서 가장 저렴한 그린피 (주중 평균 약 11.6만원). 고흥·완도·신안 등 남해안 섬 리조트 코스 다수.

**강원도 (30개 수록)**  
하이원CC(정선), 강촌CC(춘천) 등 산악·자연 코스가 특징. 잭니클라우스GC 코리아(원주) 등 세계적 명소 포함. 동계 운영 기간 제한 있음.

**충청도 (34개 수록)**  
수도권 거주자의 '2차 선택지'. 음성·청주·천안 집중. 주중 평균 약 14.3만원으로 수도권 대비 저렴. 경부고속도로·천안논산고속도로 접근성 양호.

**제주도 (28개 수록)**  
전국 최고가 (주중 평균 약 20.5만원). 나인브릿지, 핀크스GC 등 세계 100대 코스 다수. 27개 코스 중 리조트형이 다수.

### 알려진 데이터 한계

- **미수록 코스 가격**: 경기도 stub 111개는 가격 데이터 없음 (사용자 직접 입력 가능)
- **가격 변동**: 그린피는 시즌·요일·예약 경로에 따라 다를 수 있음. 현장 확인 권장
- **회원제 코스 그린피**: 비회원 라운드가 가능한 경우에만 기재. 불가 코스는 null
- **9홀 코스**: 전체 코스의 일부는 9홀 단독 운영 코스 포함
- **충청도 count**: 중복 제거 후 34개 수록 (공식 통계 75개 대비 DB 커버리지 45%)
